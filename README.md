# sutil-nfe

Aplicacao para organizar e processar dados de NFe, com backend Spring Boot e frontend React/Vite.

## Estrutura

- `src/`: backend Java com Spring Boot.
- `frontend/sutil-nfe/`: frontend React.
- `NFEs/`: arquivos locais de notas fiscais, ignorados pelo Git.

## Desenvolvimento

Backend:

```bash
./mvnw spring-boot:run
```

Frontend:

```bash
cd frontend/sutil-nfe
npm run dev
```
